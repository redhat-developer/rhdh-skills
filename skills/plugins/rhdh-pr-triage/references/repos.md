# Install Repositories

The triage skill covers RHDH install repositories — the repos that produce the
artifacts a customer installs.

| Repository | Content |
|---|---|
| `redhat-developer/rhdh-operator` | Kubernetes operator |
| `redhat-developer/rhdh-chart` | Helm chart |
| `redhat-developer/rhdh-must-gather` | Must-gather diagnostic image |
| `redhat-developer/rhdh-local` | Local development environment |
